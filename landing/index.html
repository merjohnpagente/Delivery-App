How to install

  1. Tap Download APK on your Android phone.
  2. Allow Install unknown apps when asked.
  3. Open Bings, register, and order.

Latest build always comes from GitHub Releases (latest tag, auto-built from main). Admin demo: register, then set your user role to admin in Firestore.

About Bings

Bings is a full-stack food delivery app built with Flutter and Firebase. Order food, manage your cart, checkout, and watch your rider arrive live on the map.

  • Home with search, categories, and rated food grid
  • Food details with quantity and add to cart
  • Checkout with address and payment method
  • Order history plus live rider tracking with route and ETA
  • Admin panel for orders, foods, and categories

Tech: Flutter · Firebase Auth · Firestore · Storage · Google Maps · Package com.bings.app

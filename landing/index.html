How to install

  1. Tap Download APK on your Android phone.
  2. Allow Install unknown apps when asked.
  3. Open BINGS, register, and order.

Latest build always comes from GitHub Releases (latest tag, auto-built from main). Admin demo: register, then set your user role to admin in Firestore.
